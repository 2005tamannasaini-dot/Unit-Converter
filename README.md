# Unit Converter

A Python-based project to convert length and temperature units.

## Features
- Kilometers to Meters
- Meters to Centimeters
- Kilometers to Miles
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Input validation
- Menu-driven program
- Repeat conversion using while loop

## Technologies Used
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run the command:

   python UnitConverter.py
